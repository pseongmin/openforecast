# openforecast

Open forecasting agents for public benchmarks.

| Target | What it does | Status |
|---|---|---|
| `forecastbench/` | Biweekly [ForecastBench](https://www.forecastbench.org/) forecast sets (500 questions: 250 prediction-market + 250 time-series) | building |
| `metaculus/` | Bot for the [Metaculus FutureEval](https://www.metaculus.com/futureeval/) Fall 2026 tournament and MiniBench | building |
| `agenthon/` | [Agenthon 2026](https://www.agenthon.net/) Track 2 forecasting agent (CRPS composite, Docker) | building |
| `core/` | Shared: question models, public data fetchers, calibration, scoring | building |

## Data policy

This repository uses **public data only**. See [DATA_POLICY.md](DATA_POLICY.md).
No proprietary datasets, no employer data, no private trading records, and no code from any
non-public repository are used anywhere in this project.
